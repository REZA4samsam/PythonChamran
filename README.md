# ماشین حساب پایتون (Python Calculator)

یک ماشین حساب ساده و کاربردی که با زبان برنامه‌نویسی پایتون ساخته شده است. این برنامه در محیط ترمینال اجرا می‌شود و دارای رابط کاربری رنگی و منوی انتخاب عملیات است.

# درباره پروژه

این پروژه با هدف تمرین و یادگیری مفاهیم پایه برنامه‌نویسی پایتون طراحی شده است.

ماشین حساب می‌تواند چهار عمل اصلی ریاضی را انجام دهد و به کاربر اجازه می‌دهد بدون اجرای مجدد برنامه، محاسبات متعددی انجام دهد.

# امکانات برنامه

- + انجام عملیات جمع
- - انجام عملیات تفریق
- × انجام عملیات ضرب
- ÷ انجام عملیات تقسیم
-  رابط کاربری رنگی در محیط ترمینال
-  امکان محاسبه مجدد
-  خروج از برنامه با وارد کردن حرف E
-  مدیریت ورودی‌های نامعتبر
-  جلوگیری از تقسیم بر صفر

# پیش‌نیازها

برای اجرای این برنامه به موارد زیر نیاز دارید:

- نصب Python نسخه 3 یا بالاتر
- یک محیط اجرای کد پایتون مانند VS Code یا ترمینال

**نکته:** این پروژه به هیچ کتابخانه خارجی نیاز ندارد.

# نحوه اجرای برنامه

ابتدا فایل پروژه را دریافت کنید.

سپس ترمینال را در پوشه پروژه باز کرده و دستور زیر را اجرا کنید:

```bash
python calculator.py
```

# راهنمای استفاده

| ورودی | عملکرد |
|---|---|
| + | جمع |
| - | تفریق |
| * یا × | ضرب |
| / یا ÷ | تقسیم |
| A | محاسبه مجدد |
| E | خروج از برنامه |

# نمونه خروجی

```text
========================================
       PYTHON CALCULATOR
========================================

NUMBER: 10
NUMBER: 5

========================================
RESULT: 10 × 5 = 50
========================================
```

# مفاهیم استفاده شده در پروژه

- متغیرها و انواع داده
- شرط‌های if و elif
- حلقه while
- دستورات break و continue
- مدیریت خطا با try و except
- تعریف تابع با def
- استفاده از ماژول os
- رنگ‌بندی ترمینال با کدهای ANSI
