#  رسم مستطیل با پایتون

یک برنامه ساده با زبان پایتون برای رسم مستطیل در محیط ترمینال.

##  درباره برنامه

این برنامه با استفاده از حلقه‌های `for` و کاراکترهای متنی، یک مستطیل را در محیط ترمینال رسم می‌کند.

##  امکانات

- رسم مستطیل با کاراکترهای متنی
- تعیین عرض و ارتفاع مستطیل
- استفاده از حلقه‌های تکرار
- نمایش شکل در محیط ترمینال

##  ابزارهای استفاده شده

- Python 3
- حلقه for
- دستور print
- دستور range
- دستور end

## نحوه اجرا

برای اجرای برنامه، دستور زیر را وارد کنید:

```bash
python rectangle.py
```

## هدف پروژه

این برنامه یک تمرین ساده برای یادگیری حلقه‌های تکرار و نحوه چاپ اشکال در پایتون است.
