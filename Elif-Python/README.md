#  برنامه بررسی نمره دانش‌آموز

یک برنامه ساده با زبان پایتون برای بررسی نمرات دانش‌آموزان.

## درباره برنامه

این برنامه نمره دانش‌آموز را از کاربر دریافت می‌کند و بر اساس نمره، وضعیت آن را نمایش می‌دهد.

## امکانات

- دریافت نمره از کاربر
- بررسی نمره بین ۰ تا ۲۰
- نمایش وضعیت نمره
- امکان وارد کردن چند نمره
- خروج از برنامه با وارد کردن کلمه NONE
- جلوگیری از وارد کردن متن به جای عدد

## وضعیت نمرات

| نمره | نتیجه |
|---|---|
| کمتر یا مساوی ۱۱ | ضعیف (Terrible) |
| بیشتر از ۱۱ تا ۱۵ | بد نیست (Not Bad) |
| بیشتر از ۱۵ تا ۲۰ | عالی (Perfect) |
| کمتر از ۰ یا بیشتر از ۲۰ | هشدار |

## نحوه اجرا

برای اجرای برنامه، دستور زیر را در ترمینال وارد کنید:

```bash
python elif-python.py
```

- Python 3
- حلقه while
- شرط‌های if و elif
- دستور try و except
- تبدیل داده با float
- دستور break
