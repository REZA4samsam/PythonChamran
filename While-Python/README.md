# ⌨️ توقف برنامه با فشردن کلید

یک برنامه ساده با زبان پایتون که با فشردن یک کلید مشخص، اجرای برنامه را متوقف می‌کند.

## درباره پروژه

این برنامه با استفاده از حلقه `while` به صورت مداوم یک پیام را نمایش می‌دهد.

کاربر می‌تواند با فشردن حرف C برنامه را متوقف کند.

## امکانات

- نمایش مداوم پیام در ترمینال
- بررسی فشردن کلید توسط کاربر
- توقف برنامه با حرف C
- استفاده از تأخیر زمانی بین پیام‌ها

## ابزارهای استفاده شده
- کتابخانه msvcrt
- کتابخانه time
- حلقه while
- شرط if

## نحوه اجرا

برای اجرای برنامه در ویندوز، دستور زیر را وارد کنید:

```bash
python Key-Press-Stop.py
```

## راهنمای استفاده

| کلید | عملکرد |
|---|---|
| C | توقف برنامه |
